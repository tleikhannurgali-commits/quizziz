# nur1k_2§ — AnswerBank Edition 1.0.4

Независимое расширение Firefox Android для учебных тренировок Wayground/Quizizz.

## Источник базы

- В пользовательском ZIP **31 скриншот** обзора Wayground.
- Из них **29 уникальных вопросов** из 30; вопросы №26 и №27 продублированы, вопрос №15 отсутствует.
- В базу попадают только **зелёные отметки правильных ответов**. Красные «Ваш ответ» не считаются правильными.
- **7 записей** содержат несколько правильных ответов: №1, 7, 11, 14, 18, 24 и новая формулировка №31.
- В №14 правильными помечены все 4 варианта (Қолөнер, сауда, егіншілік, малшаруашылық), несмотря на частичный балл при попытке.
- Формулировки переписаны со скриншотов; в №24 длинная строка обрывалась по правому краю, поэтому её середина восстановлена по читаемому контексту. В №27 сохранена опечатка на скрине и добавлен алиас «түрік».
- Сопоставление не является независимой проверкой исторической точности.

## Возможности

- Сравнение вопроса по нормализованному тексту и локальным близким формулировкам, **без сети**.
- Когда вопрос явно перефразирован — опциональное сопоставление через Gemini (`gemini-3.1-flash-lite` по умолчанию). Нужен личный API-ключ, модель должна быть доступна для этого ключа.
- Gemini выбирает только ID записи, НЕ придумывает ответ; варианты проверяются локально и только среди видимых вариантов.
- Поддержка случайного порядка и нескольких правильных вариантов. Если хотя бы один не сопоставлен или совпадение неоднозначно — подсветки нет.
- Плавающая кнопка, Glass UI, автоанализ, настройка видимости обводки.
- Не отправляет ответы и не нажимает за пользователя; не анализирует скрытые ответы сайта.

## Установка

Подпиши ZIP как **новое Unlisted add-on** на Mozilla Add-ons Developer Hub, скачай подписанный XPI, установи в Firefox Android. Это независимое дополнение со своим Gecko ID, не обновление `nur1k_1§` или основной 0.3.3.

Для текста, не совпадающего с базой, включи Semantic AI в настройках и укажи Gemini API-ключ. При включении этой функции текст вопроса, варианты и база передаются Google; локальные точные совпадения в Google не отправляются.

## Ограничения

Реальная работа с Wayground и живым Gemini API в Firefox Android **не тестировалась**: выполнены локальные тесты сопоставления и макетных запросов.
